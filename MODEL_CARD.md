## Which training run

The free-tier "v2, run 2" Kaggle run of 2026-06-11: a P100 GPU, torch 2.4.1 + transformers
4.49.0, about 54 minutes. The run saved its own `TrainingArguments` (`training_args.bin`,
read into the provenance record): 3 epochs, batch 16, learning rate 2e-5, linear schedule,
warmup 0.06, weight decay 0.01, seed 42, fp16, gradient checkpointing, `group_by_length`.
These match [`training/configs/v2.json`](training/configs/v2.json).

## Which data

28,500 training rows:
- 10,000 from RAGTruth (`wandb/RAGTruth-processed` @ `eb4f4b9d`), with the question dropped on ~50% of rows.
- 16,000 from VitaminC (`tals/vitaminc` @ `be6febb7`, CC BY-SA 3.0): SUPPORTS → grounded; REFUTES and NOT ENOUGH INFO → hallucinated.
- 2,500 rule-based one-fact flips of grounded RAGTruth answers.

No LLM-generated data and no private data. Builders: [`training/`](training/README.md).
The training set's hard negatives can't be regenerated byte-for-byte (hash-seed
dependence in the original script; see the training README). The test sets the headline
numbers use are reproduced exactly.

## Evaluation (measured in this repository)

The 512-token protocol, matching how the run published its numbers. CPU, pinned revision.

| Suite | Result | Published by the run |
|---|---|---|
| RAGTruth test (first 2,500 of 2,700) | F1 0.6817 [0.6579, 0.7046], acc 0.7464, P 0.629, R 0.745 | F1 0.6824, acc 0.7468 |
| VitaminC test (2,000) | acc 0.8500, F1 0.8452 | acc 0.8495, F1 0.8446 |
| One-fact flips, regenerated (500 + 500) | 78.0% caught, 76.0% unflipped kept | 80.4% / 76.2% (original sample, not recoverable) |
| Manual cases | 5/5, P(hallucinated) within 0.02 of logged values | 5/5 |

At the package default `max_length=2048`, RAGTruth F1 is 0.6955 [0.6717, 0.7179]. That's a
paired ΔF1 of +0.014 (95% CI −0.001 to +0.028) against 512 on the same rows.
Reports: [`eval/reports/`](eval/reports/).

The GPT-4-turbo prompt-judge figure (F1 0.634, RAGTruth paper) comes from a different
protocol and wasn't run head-to-head.

## Intended use

A post-generation check in RAG pipelines: flag answers the retrieved source doesn't
support, so they can be routed to review, regeneration or a stronger checker. It's not a
fact-checker against world knowledge.

## Limitations

- English only. Answer-level, not span-level.
- Long sources are truncated: 76% of RAGTruth test pairs exceed 512 tokens and 19 of
  2,500 exceed 2,048.
- Precision on RAGTruth is about 0.63, and about a quarter of grounded answers in the
  minimal-edit holdout are flagged. Tune the threshold on your own data.
- Not evaluated on adversarial or out-of-domain inputs.
- Training data terms: RAGTruth's source passages include MS MARCO and Yelp, whose terms
  are non-commercial. The weights are MIT. See the README's License section and
  `DATA_LICENSES.md` before any commercial use.
